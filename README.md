# SmartLibPortal

**SmartLibPortal** is a web-based Library Management System designed to simplify the management of books, students, and library records. It provides an easy-to-use interface for managing library operations and maintaining organized records.

### Tech Stack

* **Frontend:** HTML, CSS, Bootstrap
* **Backend:** PHP
* **Database:** MySQL
* **Tools:** XAMPP, VS Code

### Key Features

* Student Management
* Book Management
* Add, Update & Delete Records
* Book Search
* Library Record Management
* User-Friendly Interface
